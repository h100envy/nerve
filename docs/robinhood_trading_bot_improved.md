# Replaced by NERVE Protocol

The project vector is now NERVE Protocol: six typed agents, deterministic
reflexes and an on-chain execution boundary for memecoin pools. The current
article and implementation live in [docs/nerve_protocol.md](nerve_protocol.md)
and `src/nerve/`.

The former Robinhood brokerage/MCP implementation remains in the repository as
legacy code for reference; it is not part of the NERVE pipeline.
